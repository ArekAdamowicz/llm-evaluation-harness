Write a Python function named calculate_average(numbers: list[float]) -> float that calculates the arithmetic mean of the numbers in the input list.

Requirements:
- Accept a non-empty Python list containing integers or floating-point numbers.
- Accept Python integers of arbitrary size, including integers that cannot be represented as finite Python floats.
- Reject Boolean values explicitly, even though bool is a subclass of int in Python.
- If the input is not a list, raise a TypeError with the exact message: "numbers must be a list".
- If the input list is empty, raise a ValueError with the exact message: "numbers must not be empty".
- Reject unsupported element types, including strings, None, and Boolean values. Raise a TypeError with the exact message: "all elements must be int or float, excluding bool".
- Reject NaN values with a ValueError and the exact message: "numbers must not contain NaN values".
- Reject positive and negative Infinity values with a ValueError and the exact message: "numbers must not contain infinite values".
- Validate the types of all input elements before performing numerical conversion or calculation.
- Calculate the mathematical arithmetic mean without prematurely converting individual integers to floats.
- Preserve the contribution of all input values, including cases involving very large integers and cancellation between large positive and negative values.
- For floating-point inputs, respect the actual values represented by the supplied Python floats.
- Use exact intermediate arithmetic or an equivalent approach that avoids loss of information and intermediate floating-point overflow.
- A representable final mean must be returned as a finite Python float, even if individual input values or intermediate calculations exceed the representable range of Python float.
- Convert only the final mathematical mean to a Python float, using standard Python float conversion and rounding behavior.
- If the final mean cannot be represented as a finite float, raise a ValueError with the exact message: "calculation resulted in overflow".
- The result must be independent of the order of valid input elements, within normal floating-point tolerance.
- Adding a constant to every input element must increase the calculated mean by that constant, within normal floating-point tolerance.
- Do not modify the original input list.
- Include type annotations.
- Include a descriptive docstring explaining the function's purpose, accepted inputs, return value, and possible exceptions.
- The implementation must satisfy all requirements without relying on a specific numerical summation algorithm or library.
